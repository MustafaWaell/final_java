 **EL Metbarmaga MN B.Laban Quick Pay**
 
Project Overview:
EL Metbarmaga MN B.Laban Quick Pay is a simple digital wallet simulation made using Java. It allows users to check their balance, transfer money to other users, view their transaction history, and manage favorite contacts.
The project also has an Admin Panel for managing users and checking transactions.
Note: This project is for educational purposes only. It does not handle real money.
(====Features====)
Login as Admin or User.
Check wallet balance.
Transfer money between users.
View transaction history.
Add and remove favorite contacts.
Search for users and recipients.
View and update user profiles.
Block and unblock accounts.
View application statistics.
(====Admin Panel====)


Show application statistics.
Search for a user by ID, name, phone number, or email.
View all registered users.
Update user information.
View all transactions.
Block and unblock accounts.
View user details.
(==== User Panel ====)
The User can:
Check their balance.
Transfer money to another user.
View their transaction history.
Add and remove favorite contacts.
View favorite contacts.
Search for a recipient.
View and update their profile.
Log out of their account.
(==== Money Transfer Rules ====)
Before completing a transfer, the program checks that:
The recipient exists.
The sender and recipient are different users.
Both accounts are active.
The transfer amount is greater than zero.
The sender has enough money.
If the transfer is successful, the sender's balance decreases and the recipient's balance increases by the same amount. If the transfer fails, neither balance should change.
